# Testing Tuck

Thanks for helping test Tuck. This takes about 15 minutes, then just use it as normal for a week.

Please [open an issue](https://github.com/aswin099/tuck/issues/new/choose) for anything that goes wrong or confuses you, and include your macOS or Windows version.

## Mac

Install it by following [Option 1 in the README](README.md#option-1-download-the-app-easiest), then check:

### First run
- [ ] You could install and open Tuck without help
- [ ] The Tuck icon shows in the menu bar
- [ ] ⇧⌘V opens the popup in any app
- [ ] Nothing asks for permissions on first run, and ↩ copies the item so ⌘V pastes it
- [ ] Turning on *Paste into the active app* asks for Accessibility, and ↩ pastes once it's allowed

### Everyday use
- [ ] Text, links, images and files all appear in the history
- [ ] Search finds an old item
- [ ] ↩ and ⌘1–9 copy (or paste, with auto-paste on) the item you want
- [ ] ⌘P pins an item, and ⌘⌫ deletes one
- [ ] ⌘Y shows the preview pane
- [ ] ⇥ adds items to the queue, and ⌃⌘V gives them back oldest first

### Privacy
- [ ] A password copied from a password manager isn't saved
- [ ] A copied API key or token is hidden, then disappears after a few minutes
- [ ] Nothing is saved from an app you added to the ignored apps list

### Settings
- [ ] Each shortcut can be changed, and the new one works
- [ ] The window stays the same size when you switch tabs
- [ ] *Open Tuck at login* works after a restart

### Staying power
- [ ] History and pins survive quitting Tuck
- [ ] History and pins survive a restart
- [ ] After a week: no crashes, no missing history, and no slowdown

### Updating
When a new version comes out, follow [Update in the README](README.md#update), then check:
- [ ] History and pins are still there
- [ ] Pasting still works

## Windows

Windows builds have never been run on a real PC, so every result helps. Download `Tuck-Windows-x64.zip` (`Tuck-Windows-arm64.zip` for Windows on ARM) from the [Releases page](https://github.com/aswin099/tuck/releases). Windows shows a SmartScreen warning because Tuck isn't signed: click **More info**, then **Run anyway**.

- [ ] Tuck starts and its icon shows in the system tray
- [ ] Ctrl+Shift+V opens the popup in any app
- [ ] Picking an item pastes it into the app you were using
- [ ] Ctrl+Alt+V pastes the queue, oldest first
- [ ] Each shortcut can be changed, and the new one works
- [ ] History survives quitting Tuck and restarting the PC
- [ ] Light and dark mode both look right
